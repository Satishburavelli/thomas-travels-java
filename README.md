# Driver Management System — Thomas Travels

Java OOP-based application to automate driver
and travel service management.

## Tech Stack
- Java
- OOP (Encapsulation, Constructors)
- Collections Framework (ArrayList)
- Eclipse IDE

## Classes
| Class | Purpose |
| Driver.java | Entity class — attributes, getters, setters |
| Travel.java | Service class — 5 business logic methods |
| TestDriver.java | Main/Tester class |

## Key Features
- Verify if driver belongs to Car category
- Retrieve driver details by ID
- Count drivers by category
- Filter drivers by category
- Find driver with maximum distance travelled

## Concepts Used
- Encapsulation & Abstraction
- Parameterized Constructors
- ArrayList iteration
- Service layer separation
- Method overloading principles
